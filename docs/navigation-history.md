# 导航历史

0.0.16 新增首页「我的」，按开始时间倒序展示最近 200 次导航，包括目的地和地址、开始/结束时间、导航时长、状态，以及出发时所选路线的规划里程。导航时长包含停留；规划里程不表示实际行驶距离。支持单条删除、确认后清空全部历史，并提供车道采集诊断入口。

只有收到 GPS 导航开始事件才新建记录。搜索、选路线、取消和模拟不记录；重复开始事件不多记。SDK 停止、实际到达、页面退出、主动取消和导航异常分别结束记录；同一会话先停止后到达时允许修正为已到达，到达状态不会被后续退出覆盖，旧会话回调不可修改新导航。

记录存于应用私有目录 `filesDir/navigation-history-v1.json`。开始时立即保存，结束时更新，先写临时文件再原子替换。写入失败显示错误并保留原文件，不阻断导航；开始写入失败后，结束时会再次尝试。文件读取上限 1 MB，损坏或未知版本不被新记录静默覆盖。

应用重新创建窗口时，将上次未结束的记录标为「未正常结束」，结束时间及完整时长显示未记录。历史只保存目的地摘要，不保存当前位置、坐标、Key 或完整轨迹，不上传。删除导航历史不会清除车道缓存和采集诊断。旧版本没有这类记录，不能从采集诊断补录目的地和行驶过程。

验证：68 项宿主机逻辑测试和签名构建通过。真机检查了「我的」入口与空状态、短时 GPS 导航开始立即写入、退出后更新为已结束、目的地/时间/规划里程展示、重启保留、清空弹窗取消及单条删除。调试记录已清理，系统位置服务临时开启后恢复为原先关闭状态；未进行道路行驶和实际到达验证，到达、中断及存储异常以逻辑测试覆盖。

## 0.0.23 去过城市搜索

目的地搜索默认先查询当前城市；有效响应中没有可选择地点时，从「已到达」导航历史按最近到达时间提取城市，逐城查询，第一个有结果的城市即停止。当前城市、城市简称和重复项合并；明确输入城市或手动选择范围时不扩大搜索。连接、权限及配额错误保留错误提示，不当成无结果；输入变化、修改范围、离页和后台会取消搜索，过期响应不能发起后续城市请求或写入搜索历史。没有识别当前城市时仍需重新定位或补充城市。

新记录在 GPS 导航开始时附带从地点搜索响应获得的目的地城市，只有实际到达状态才纳入去过城市。旧版 `version: 1` 记录仍可读取；没有城市字段时，仅识别地址开头的完整行政区城市名（可含省或自治区前缀）。未到达、失败、中断、地址不足的旧记录不推断为已去过；无法从旧数据恢复的城市可通过关键词显式搜索。

去过城市在每次打开搜索页时从现有导航历史重新计算，不另存城市足迹；删除或清空导航历史后，下次搜索会更新范围。只向地图服务发送本次关键词和逐城搜索范围，不上传导航记录、时间或完整历史。城市字段为空的旧数据无需迁移，不在调试中伪造到达记录。

验证：113 项逻辑测试与完整签名构建通过，覆盖当前城市优先、空结果逐城回退、首个命中停止、手动与明确城市限制、失败及取消边界、城市元数据持久化和旧历史兼容。0.0.23 已安装到授权手机，检查了现有到达记录识别、当前及历史城市均无结果的搜索、手动限制与恢复、明确城市搜索及选点返回。测试产生的三条搜索记录已删除；导航历史、搜索历史、车道缓存和诊断文件与安装前 SHA-256 一致。本次未进行实际道路导航和新增到达验证；回退首个命中的分支以构造响应测试覆盖。
